# FinTeens

A React app for practicing everyday money skills. Profiles and learning progress are stored locally in the browser using the existing `finteens_data` key.

## Run locally

```sh
npm install
npm run dev
```

Vite prints the local address when it starts (usually `http://localhost:5173`). For a production build, run `npm run build`.

## Learning features

- Guided onboarding and editable learner profile
- Dashboard with XP, levels, streaks, wallet, missions and goals
- Lessons, knowledge quizzes, timed speed round, scenarios, glossary and money facts
- Monthly budget planner and savings growth explorer
- Virtual wallet, expense log, savings goals and simulated market portfolio
- Purchase affordability helper and achievements

All cash balances and market activity are practice simulations. The app does not connect to a bank or place real trades.
